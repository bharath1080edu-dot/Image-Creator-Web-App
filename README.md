# Image Creator – UPVC Windows, Doors & Interiors Website

A modern, high-performance, and fully responsive showcase website for **Image Creator** (Bangalore), premier manufacturer of precision-engineered UPVC windows, sliding doors, and turnkey luxury home interiors.

---

## 🌟 Features

- **Modern Hero Experience**: Dynamic rotating quote banner, gradient accents, and quick-action consultation links.
- **Complete Product Catalog**: High-resolution showcase of Casement Windows, Sliding Systems, French Balcony Doors, Picture Windows, Top-Hung Awnings, and Louver Ventilators.
- **Turnkey Interior Solutions**: Visual gallery highlighting Modular Kitchens, Designer Wardrobes, Fluted TV Consoles, and Living Room designs.
- **Interactive Customizer & Features**: Specification highlights, color profiles (White, Dark Oak, Golden Oak, Anthracite Grey), acoustic insulation, and multi-point security.
- **Direct Lead Capture**: Integrated appointment booking modal and direct one-click WhatsApp quote requests.
- **Zero-Dependency Core**: Pure HTML5, modern CSS3 (Custom Properties / Design Tokens), and vanilla JavaScript.

## 🚀 Getting Started

### Prerequisites

- Any modern browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari)
- [Node.js](https://nodejs.org/) (optional, for local development server)

### Running Locally

1. **Option 1: Node.js (Recommended)**
   ```bash
   npm start
   ```
   Open [http://localhost:8080](http://localhost:8080) in your browser.

2. **Option 2: Python HTTP Server**
   ```bash
   python -m http.server 8080
   ```
   Open [http://localhost:8080](http://localhost:8080) in your browser.

3. **Option 3: Direct Browser Launch**
   Double-click `index.html` to open it directly.

---

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Push this repository to GitHub.
2. In your repository on GitHub, go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your website will be live in a few moments!
